LEGENDS OF ETHERIA — FIRST PLAYABLE MILESTONE

NO TERMINAL / NO NPM / NO NODE / NO VITE

HOW TO OPEN
1. Keep the folder layout unchanged.
2. Double-click index.html to open in a modern browser.
3. Internet is currently required for the Babylon.js, Babylon GLB loader and Phaser 3 libraries loaded from their CDNs.
4. For GitHub Pages, upload all files preserving their relative paths.

ENGINE
- Phaser 3.90.0 drives the game runtime/update loop and ambient 2D particle effects.
- Babylon.js renders the true 3D environment, characters, camera, lighting, shadows and spell meshes. Phaser 3 is a 2D framework and does not natively render 3D.
- All source is plain JavaScript (not TypeScript) so the browser can run it without a compile/build step. The source folders mirror the agreed architecture.

TOOLS / ASSET PIPELINE
- VS Code: source editing and folder management.
- Phaser 3: game runtime, scene/update orchestration, effects and input systems.
- Babylon.js: 3D renderer added to honour the full-3D requirement.
- Krita: planned source for painted textures and UI images; no Krita-authored final assets are included yet.
- Aseprite/LibreSprite: planned sprite sheets for icons, portraits and effects; none included yet.
- Blender: planned source for final rigged GLB models; procedural placeholder meshes are used for now.
- Tiled: planned map-layout authoring; the first forest layout is currently generated by code. Phaser supports Tiled JSON tilemaps.

CONTROLS
WASD move · Middle mouse drag rotates camera · Mouse wheel zooms · Space basic attack · Shift defend · E interact · 1 Arcane Bolt · Q Healing Wave · 2 Frost Nova · Tab target · Right-click party commands · Esc pause · P opens planning while paused.

FIRST MILESTONE
A base and one Emerald Forest region, character creation, companions, recruitable healer, wolf AI, Grove Guardian boss, real-time combat, abilities, health/mana, party commands, adjustable camera, graphics settings, time/weather, save/load and export/import.
